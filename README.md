# Telegram-бот для учёта финансов

Минималистичный бот для записи доходов и расходов. Он сохраняет категорию,
сумму, необязательный комментарий, а также дату и время операции.

## Возможности

- добавление расхода или дохода за несколько нажатий;
- отдельные и пользовательские категории для расходов и доходов;
- быстрые суммы и возможность ввести любую сумму вручную;
- кнопки возврата на предыдущий шаг и отмены;
- автоматическое сохранение даты и времени;
- сводка за сегодня, текущий месяц или всё время;
- пять крупнейших категорий расходов;
- история последних 10 операций с фильтром доходов и расходов;
- необязательные комментарии к операциям;
- безопасное удаление последней операции с подтверждением;
- отдельные данные для каждого пользователя Telegram.
- защищённая быстрая запись с iPhone через «Команды» и Пункт управления;
- единые категории и общая база для Telegram и iPhone.
- несколько счетов с начальными и фактическими остатками;
- карты, депозиты и наличные в тенге, рублях или долларах;
- автоматическое списание и зачисление по выбранному счёту;
- перевод средств между счетами без искажения статистики доходов и расходов;
- создание счетов и выбор счёта в быстрой форме iPhone.
- самостоятельный сайт и Telegram Mini App на одной базе Neon;
- регистрация, вход и восстановление пароля по email;
- автоматическая авторизация при открытии Mini App из Telegram;
- админский просмотр пользователей и их счетов в режиме только чтения.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Установите Python 3.9 или новее.
3. В папке проекта выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

4. Откройте `.env`, вставьте токен и запустите бота:

```bash
python bot.py
```

Локально бот работает, пока запущен процесс `python bot.py`. В Vercel он
работает через Telegram webhook, а сайт и бот используют одну базу Neon.

## Настройки

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен от BotFather | обязательна |
| `BOT_TIMEZONE` | Часовой пояс для даты и времени | `Asia/Almaty` |
| `DATABASE_URL` | Строка подключения к Neon Postgres | обязательна в production |
| `PUBLIC_BASE_URL` | Публичный HTTPS-адрес сайта | адрес Vercel |
| `TELEGRAM_WEBHOOK_SECRET` | Секрет проверки Telegram webhook | обязательна в production |
| `NEON_AUTH_BASE_URL` | Адрес Managed Neon Auth | обязательна для веб-входа |
| `NEON_AUTH_JWKS_URL` | Ключи проверки токенов Neon Auth | обязательна для веб-входа |
| `ADMIN_TELEGRAM_IDS` | Telegram ID администраторов через запятую | пусто |

## Быстрая запись с iPhone

1. Откройте бота и нажмите `📱 iPhone`.
2. Нажмите `⚡ Настроить команду iPhone`.
3. Скопируйте персональный ключ и адреса API из инструкции.
4. В приложении «Команды» один раз соберите пошаговую команду из действий
   `Выбрать из меню`, `Выбрать из списка`, `Запросить ввод` и
   `Получить содержимое URL`.
5. В Пункте управления iPhone нажмите `+`, выберите элемент `Команда`
   и укажите созданную команду Purpose Finance.

После настройки команда показывает небольшие системные окна поверх текущего
приложения. Она не открывает сайт, а отправляет результат напрямую в API и ту
же базу, которую используют сайт и Telegram-бот.

Персональная ссылка является ключом доступа. Повторное нажатие `📱 iPhone`
создаёт новый ключ и отключает предыдущий.

## Счета и начальные остатки

Откройте `💳 Счета`, чтобы создать карту, депозит или наличные и указать
сумму, которая уже находится на нём. Для депозита можно сохранить годовую
ставку. Каждый новый доход или
расход предлагает выбрать счёт и автоматически меняет его остаток. В этом же
разделе можно установить фактический остаток и выполнить `Перевод средств`.

## Администратор

1. Отправьте боту `/myid`.
2. Добавьте полученный ID в переменную Vercel `ADMIN_TELEGRAM_IDS`.
3. Выполните новый production deployment.

После этого команда `/admin` в боте и кнопка `Пользователи` на сайте покажут
счета других пользователей. Обычные пользователи не могут запрашивать чужие
данные, а админский режим не позволяет изменять их записи.
