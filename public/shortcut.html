Нативная быстрая запись

После однократной настройки команда будет показывать небольшие системные окна сверху — сайт открываться не будет.

1. Создайте команду

Откройте приложение «Команды», нажмите «+» и назовите команду Purpose Finance.

Открыть «Команды»

2. Сохраните персональный ключ

Не отправляйте его другим: ключ даёт доступ только к вашим финансовым данным.

3. Добавьте действия

  1. «Выбрать из меню»: Расход / Доход. Сохраните результат как kind: expense или income.
  2. «Получить содержимое URL» методом GET: URL ниже, заголовок Authorization = Bearer персональный_ключ.
  3. Из словаря ответа возьмите category_labels → «Выбрать из списка», затем account_labels → «Выбрать из списка».
  4. Добавьте «Запросить ввод» для суммы и ещё один — для необязательного комментария.
  5. «Получить содержимое URL» методом POST на адрес сохранения. Тип тела — JSON, заголовок Authorization такой же.
  6. Добавьте «Показать уведомление»: операция сохранена.
